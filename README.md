# pairwise-audiofade

## 题面（可直接粘贴）

音频淡入淡出与交叉淡化。约束：淡入从 0 到原值、淡出从原值到 0；交叉淡化两端能量连续且总功率不突跳；48kHz 一小时（1.7 亿样本）流式处理峰值内存不超过 8 MB；100 万样本不超过 200 ms；长度不符与非法长度要给出可区分的错误；并发处理不同缓冲区安全。验收：python -m pytest tests -q -k fade。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 10 万样本耗时
- 并发
- 非有限样本
- 短输入
- 立体声逐声道

## 运行方式

```bash
python -m pytest tests -q
```
